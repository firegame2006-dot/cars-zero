# Velora Motors — сайт автосалону

Демонстраційний (портфоліо) сайт автосалону: три відеосекції з новинками та кастомними
збірками, каталог з 24 авто, окреме СТО, адмінпанель і три мови інтерфейсу.

> **Усі контакти вигадані.** Телефон, пошта, адреси, соцмережі та карта — демонстраційні.
> Останні цифри номера приховані зірочками, а натискання показує підказку, що номер тестовий.

## Запуск

```bash
python server.py
```

Сайт відкриється на `http://localhost:8000/`, адмінпанель — `http://localhost:8000/admin.html`
(демо-пароль `admin`). Інший порт: `python server.py 8080`.

Сайт працює і без сервера — можна просто відкрити `index.html` у браузері. Тоді каталог
береться з `assets/js/seed.js`, а зміни з адмінки зберігаються в `localStorage` браузера.

## Сторінки

| Файл | Що всередині |
|---|---|
| `index.html` | Головна: банер із пошуком, три ролики, добірка авто, СТО, показники |
| | Вкладки банера ведуть у каталог, контакти й до кастому, бренди — у каталог з фільтром |
| `showcase.html` | Новинки та кастом — три ролики великим планом |
| `catalog.html` | Каталог: пошук, 11 фільтрів, сортування, порції по 10 авто |
| `car.html?id=…` | Сторінка авто: галерея з гортанням, характеристики, схожі авто |
| `service.html` | СТО: 6 послуг із цінами та запис на сервіс |
| `about.html` | Про компанію |
| `contacts.html` | Контакти, демо-карта, форма звʼязку |
| `admin.html` | Адмінпанель: додати / змінити / видалити авто (посилання на сайті немає — лише прямою адресою) |

Перехід між розділами — це окремі сторінки, а не прокрутка однієї довгої.

## Каталог

* 24 автомобілі: нові та з пробігом, у кожного рік, пробіг, стан, кількість власників, VIN,
  комплектація, місто та опис трьома мовами.
* По три фотографії на авто: загальний план і два деталізовані кадри.
* Номерні знаки на всіх фото каталогу заретушовані (розмиті).
* Показується 10 авто, далі — кругла стрілка «Показати ще» (ще 10). Коли показано все,
  стрілка перетворюється на «Згорнути каталог». Нескінченної прокрутки немає.
* Стан фільтрів зберігається в адресі сторінки, тож посилання можна надіслати комусь.

## Пошук

* Розуміє кирилицю та латиницю: `бмв`, `мерседес`, `кайєн`, `туарег`.
* Терпить помилки: `porshe`, `mersedes` знаходять потрібне авто.
* Розуміє суми та роки: `bmw до 90000`, `від 2022`.
* Живі підказки з фото, клавіші ↑ ↓ Enter, `/` — швидкий фокус на полі пошуку.
* Спершу шукає точні збіги і лише якщо їх немає — вмикає пошук з помилками.

## Адмінпанель

`admin.html`, демо-пароль `admin`. Посилання на неї з сайту прибрано — відкривається лише прямою адресою.

* Додавання, редагування та видалення авто, пошук по списку.
* Кілька фотографій: файли з компʼютера (зберігаються як data:URL) або шляхи, по одному в рядку.
  Перше фото — головне.
* Експорт та імпорт `JSON`, повернення до заводського каталогу.
* Із запущеним `server.py` дані пишуться у `data/cars.json`, без нього — у `localStorage`.

## Мови

Українська, англійська, польська. Перемикач у шапці, вибір запамʼятовується.

## Дрібниці

* Ролики без звукової доріжки і без жодних кнопок: коли користувач догортує до них,
  відео починає програватися саме, по колу, і зупиняється, щойно зникає з екрана.
* Кнопка «Записатись на огляд» і картки послуг відкривають картку запису на СТО.
* Обране (сердечка) зберігається у браузері.
* Після перезавантаження сторінка завжди відкривається згори, а не там, де зупинився читач.
* Фото автомобілів — Wikimedia Commons.

## Публікація на GitHub Pages

Репозиторій уже містить готовий статичний сайт, тому окремої збірки не потрібно:

1. На GitHub: **Settings → Pages**.
2. **Source** — *Deploy from a branch*, гілка `main`, тека `/ (root)`, **Save**.
3. За хвилину сайт буде доступний за адресою
   `https://firegame2006-dot.github.io/cars/`.

Що працює на Pages, а що ні:

* Сайт, каталог, пошук, фільтри, галереї, мови, форми — усе працює.
* Каталог читається з `data/cars.json` — редагувати можна просто в репозиторії.
* Адмінпанель (`admin.html`) без сервера зберігає зміни лише в памʼяті браузера
  (`localStorage`) і має кнопку **Експорт JSON** — цей файл можна покласти
  в `data/cars.json` і закомітити. Щоб зміни писалися у файл напряму, запускайте
  локально через `python server.py`.
